% remote-app(1) | Remote App User Manual

# NAME

remote-app - secure native remote computing client

# SYNOPSIS

`remote-app`

# DESCRIPTION

Remote App provides terminal, SSH, SFTP, Telnet, serial, VNC, RDP, forwarding,
macro, and multi-session workflows. Host keys are checked through SSH
`known_hosts`; verify first-use and changed-key fingerprints independently.

# FILES

`~/.config/remote-app/` contains the encrypted session store, non-secret
configuration, and rotating logs.
