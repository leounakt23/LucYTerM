# Events

All events below are proposed, not scheduled, given single-maintainer capacity.
Each one lists activation criteria so enthusiasm does not turn into an implied
commitment. Recordings and notes are published when an event runs.

- [Monthly community call](monthly-call.md): proposed recorded Q&A.
- [Bug Bash weekends](bug-bash.md): pre-release testing sprints.
- [Hacktoberfest](hacktoberfest.md): opt-in participation with curated issues.
- [Annual virtual conference](annual-conference.md): future talks and demos day.
