# Hacktoberfest (Proposed)

Status: opt-in per year, announced in Discussions. The project does not
guarantee participation every year.

- Curated `good-first-issue` and `help-wanted` tasks are labeled for the event.
- Maintainers give first-time authors extra review context; standards are not
  lowered for event PRs.
- Spam or low-effort PRs are closed with an explanation and reported to event
  organizers when applicable.
