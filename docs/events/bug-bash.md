# Bug Bash Weekends (Proposed)

Status: runs before a major release when a maintainer calls one in Discussions.

- Scope, builds under test, and focus areas are announced with the call.
- Participants file one report per issue with version, repro steps, and
  sanitized logs; confirmations on existing reports are equally valuable.
- No private data in reports. Security findings follow `SECURITY.md` privately.
