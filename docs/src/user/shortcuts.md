# Keyboard Shortcuts

| Shortcut | Action |
| --- | --- |
| `Ctrl+T` | New tab |
| `Ctrl+W` | Close active tab |
| `Ctrl+B` | Toggle sidebar |
| `Ctrl+K` | Show session list |
| `Ctrl+,` | Open settings |
| `Ctrl+Shift+M` | Toggle multi-exec broadcast mode |
| `Ctrl+Shift+R` | Start or stop macro recording |
| `Ctrl+Shift+C` | Copy the active terminal selection to the clipboard |
| `Ctrl+Shift+V` | Paste the clipboard into the active terminal |
| `Ctrl+Shift+A` | Select the whole visible grid of the active terminal |
| `F5` | Play macro bound to F5 |
| `F6` | Play macro bound to F6 |
| `F7` | Play macro bound to F7 |
| `F8` | Play macro bound to F8 |

Shortcuts use Control on Linux. Meta is reserved for window-manager behavior.
