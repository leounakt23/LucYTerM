# Support

## Questions and Usage Help

Search the user guide and existing GitHub discussions first. For reproducible
bugs, open an issue with the version, distribution, installation format,
protocol, minimal steps, and sanitized logs.

Response targets, platform scope, triage, and stale-issue handling are
documented in [`docs/support.md`](docs/support.md). All targets are best-effort
unless covered by a separate written agreement.

## Security Issues

Do not use a public issue for vulnerabilities, credentials, host keys, or
private terminal content. Follow `SECURITY.md` instead.

## Community

GitHub Discussions is the primary community forum. A Matrix or Discord room
may be added when an official project-maintained space is available; do not
assume unofficial rooms are supported or safe for credentials.

New feature proposals and roadmap votes also belong in Discussions. GitHub
Issues track reproducible bugs and feature work accepted into a milestone.
