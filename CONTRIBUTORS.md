## How to Get Listed

Comment on the pinned Beta Program Discussion with the name or handle you want
published, or add a row in a pull request. Beta testers are listed in release
notes only after explicit consent. Participation and recognition never depend
on enabling telemetry or crash reporting.

## Contribution Types

Keys follow the all-contributors emoji legend, including `💻` code, `📖`
documentation, `🌍` translation, `⚠️` tests, `🐛` bug reports, `💡` ideas,
`🤔` design, `🛡️` security, and `🚇` infrastructure.

## Automation Status

- `.all-contributorsrc` is the machine-readable source of truth.
- `.github/workflows/all-contributors.yml` checks that every entry in
  `.all-contributorsrc` appears in the table above.
- Automatic table generation via the all-contributors bot is not enabled yet.
  Until it is, keep both files in sync manually in the same pull request.
